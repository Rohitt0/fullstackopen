# Bloglist — Part 7 (7.7–7.20)

Final reference implementation using:
- Express + MongoDB backend
- React + Vite frontend
- React Router
- Zustand for shared state
- Material UI
- Error boundary
- Anonymous comments
- User and blog views
- Persistent user service
- Prettier configuration

## Development

Terminal 1:
npm --prefix backend run dev

Terminal 2:
npm run dev

## Production

npm run build
npm start

The backend serves `frontend/dist`.
